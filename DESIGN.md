# DESIGN.md — MemoryVault

## Direction
Private technical archive. Landing: authentic archive/workspace image, not generic AI-brain art. IA: Overview, Memories, Projects, Search, Sources, Decisions, Collections, Settings. Figma: Foundations, Components, Landing, Memory, Search, Source/Provenance, Responsive, States.

## Figma workflow
Create Foundations (tokens), Components, Landing, Core workflow screens, Responsive, and States. Use Figma Variables/modes for tokens where useful and Dev Mode for handoff. Keep Figma and code tokens synchronized.

## Images
Use real/relevant imagery only when it improves comprehension or identity. Prefer authentic workspace/source/product screenshots where lawful. Avoid generic AI art, carousels, and decorative image overload.

## Accessibility
Contrast, visible focus, semantic labels, keyboard access, reduced motion, touch targets, responsive layout, meaningful empty/loading/error states.
